# Тренировочный блокнот

Личный дневник тренировок. Обычные HTML, CSS и JavaScript, без установки и сборки.
Данные хранятся в браузере (IndexedDB) на этом устройстве.

## Как открыть

- **Быстро посмотреть:** дважды щёлкнуть `index.html`, он откроется в Chrome или Edge.
- **Проверить тесты:** дважды щёлкнуть `tests.html`. Наверху должно быть «Все тесты пройдены».
- **На iPhone:** перетащить всю папку на https://app.netlify.com/drop. Открыть полученную ссылку в Safari,
  нажать «Поделиться», затем «На экран „Домой“».

Без сети приложение работает только при открытии по ссылке `https://…`. Если открыть файл с диска,
работа офлайн не включится, но всё остальное работает.

## Файлы

```
index.html              страница приложения
styles.css              весь дизайн (цвета и размеры — в начале файла)
manifest.webmanifest    название, иконки, режим приложения
sw.js                   офлайн-режим (при изменениях увеличьте VERSION)
icons/                  иконки 192, 512, maskable, apple-touch-icon
js/domain.js            логика: цикл 8 недель, тренировка, «прошлый раз», формат чисел
js/seed.js              программа по умолчанию и демо-история
js/db.js                хранилище IndexedDB и сценарии (начать, отметить подход, завершить)
js/anatomy.js           схемы мышц для упражнений (фигура спереди и сзади)
js/ui.js                кнопки, иконки, нижний лист
js/screens/*.js         экраны: Сегодня, Тренировка, Программа, Настройки, История
js/app.js               запуск и переходы между экранами
tests.html, tests/      тесты
```

## После изменений

1. Откройте `tests.html`, все тесты должны быть зелёными.
2. В `sw.js` увеличьте `VERSION` (например, `v3` на `v4`).
   Телефон сам скачает новую версию при следующем открытии и перезагрузится
   (во время тренировки — когда приложение свернут).
3. Иконки перерисовываются командой `node scripts/icon.mjs` (нужен пакет `sharp`).
